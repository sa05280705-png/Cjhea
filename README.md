# reels-auto · 릴스 만들기 도우미

지혜의 뜨개·가든·홈 릴스를 만드는 작은 도우미입니다.
**자동으로 올리지 않습니다.** 챗봇(Claude, ChatGPT 등)에 글을 붙여넣고, 답을 저장하고, 미리보기를 확인한 뒤 인스타그램·스레드에는 **내가 직접** 올립니다.

## 시작하기 (윈도우)
1. 컴퓨터에 **Node.js(LTS)** 가 설치되어 있어야 해요. (https://nodejs.org)
2. 폴더 안의 **start-windows.bat** 을 더블클릭하면 메뉴가 나와요. 번호를 누르고 Enter.
3. 파란 경고창(SmartScreen)이 뜨면 "추가 정보 → 실행"을 누르세요. 이 폴더에서 만든 파일이라 괜찮아요.

## 메뉴
| 번호 | 하는 일 |
|---|---|
| 1 | 오늘의 소재 고르기 (소재 목록에서 후보 5개를 보여 줘요) |
| 2 | 프롬프트 카드 만들기 → 메모장에서 전체 복사해 챗봇에 붙여넣기 |
| 3 | 챗봇 답변 저장하기 (콘티 → 캡션 → 해시태그 순서) |
| 4 | 미리보기 보기 (휴대폰 크기 화면, 올리기 전 점검 목록 포함) |
| 5 | 올린 뒤 기록 남기기 |
| 6 | 지금까지 기록 보기 |
| 7 | **사진·영상 정리하기** (장면별로 나누고 메모 달기) |
| 8 | **첨부용 사진 정리 화면 열기** (크기 줄이기·위치정보 지우기) |

## 사진·영상을 함께 쓰려면
뜨개질 과정 사진, 완성샷, 짧은 영상 클립(세로로 찍은 것)을 넣어 두세요.
1. 1번으로 소재를 고른 뒤, 파일을 **media\inbox** 폴더에 복사해 넣어요. (원본은 따로 보관!)
2. 파일 이름 앞에 숫자를 붙이면(예: `2_과정.jpg`) 그 번호 장면으로 가요. 숫자가 없으면 찍은 순서대로 장면에 나뉘어요.
3. **7번**을 누르면 `media\날짜_소재` 폴더로 옮겨 정리하고, 장면마다 한 줄 메모를 물어봐요.
4. 이후 2번 카드에 "내가 준비한 사진·영상" 설명이 들어가요. **파일 자체는 챗봇에 올라가지 않아요.** 챗봇에 사진을 직접 보여 주고 싶으면 8번 화면에서 줄인 사진을 챗봇 창에 끌어다 놓으세요.
5. 4번 미리보기에 장면마다 사진·영상이 보여요.

### 8번 화면 (out\media.html)
- 사진을 끌어다 놓으면 가로세로 1280px 이하로 줄이고, 위치(GPS)·카메라 정보를 지워서 저장해요.
- 파일은 **내 컴퓨터 안에서만** 처리돼요. 어디에도 올라가지 않아요.
- 영상은 줄이지 않고 그대로 담아요. 영상 속 위치정보는 못 지우니 폰 카메라의 위치 저장을 꺼 두세요.
- 폰 사진이 HEIC 형식이면 읽지 못해요. 폰 카메라 설정에서 "호환성 우선(JPG)"으로 바꾸거나 JPG로 보내 주세요.

## 폴더 지도
- config\profile.json : 이름·타깃·말투·장면 이름·올리는 곳·점검 목록·색 (고치면 전체에 반영돼요)
- data\ : topics.txt(소재 목록) · contis.json(만든 기록) · publish_log.json(올린 기록) · current.json(진행 중)
- prompts\ : 챗봇에 붙여넣을 글의 틀 (1_conti · 2_caption · 3_hashtags)
- inbox\ : 챗봇 답변을 붙여넣어 저장하는 곳
- media\ : 사진·영상 (inbox에 넣으면 7번이 정리)
- tools\ : 첨부용 사진 정리 화면의 틀
- out\ : 만들어진 카드·미리보기 (자동 생성)
- src\ : 프로그램

## 지켜 주세요
- 사진·영상에 **다른 사람 얼굴, 집 주소, 연락처**가 찍히지 않았는지 확인하세요.
- 이 폴더를 GitHub 같은 곳에 올릴 때 media 폴더는 제외돼요(.gitignore). 올리지 마세요.
- 소재·말투·점검 목록은 강사가 적은 **초안**이에요. 내 것에 맞게 고쳐 쓰세요.
